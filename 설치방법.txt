UV1200 웹 컨트롤 - 앱(PWA)으로 설치하기

[방법 1] Windows에서 start-windows.bat (가장 쉬움, 인터넷 필요 없음)
1. zip을 "압축 풀기"로 전부 푼 다음 (zip 안에서 바로 실행하면 안 됩니다)
2. start-windows.bat 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
3. 검은 창이 뜨고 Chrome(없으면 Edge)이 http://localhost:41200 으로 열립니다.
4. 위쪽 [앱 설치] 버튼(또는 주소창 오른쪽 설치 아이콘)을 누릅니다.
5. 바탕화면·시작 메뉴에 UV1200 아이콘이 생깁니다. 이제 검은 창을 닫아도 앱은 그대로 실행됩니다.
   (이 PC 안에서만 접속되는 서버라 다른 사람이 들어올 수 없습니다)

[방법 2] GitHub Pages (여러 PC에서 같은 주소로 쓸 때, 무료)
1. github.com에서 새 저장소(Public)를 만듭니다. 예: uv1200
2. "Add file → Upload files"로 index.html, manifest.webmanifest, sw.js, icons 폴더를 올리고 Commit 합니다.
3. Settings → Pages → Branch: main, 폴더: / (root) → Save
4. 1~2분 뒤 https://아이디.github.io/uv1200/ 을 Chrome/Edge로 열고 [앱 설치]를 누릅니다.

[새 버전으로 바꿀 때]
- 방법 1: 새 파일로 폴더를 덮어쓰고 start-windows.bat 를 다시 실행 → 앱을 열면 위쪽에 "새 버전" 알림 → [지금 업데이트]
- 방법 2: 새 파일을 GitHub에 다시 올림 → 앱을 열면 "새 버전" 알림
- 포트 번호(tools\port.txt, 기본 41200)는 되도록 바꾸지 마세요. 바뀌면 다른 앱으로 인식되어 저장된 설정·백업이 보이지 않습니다.

[설치한 앱에서 되는 것]
- M.Wave 파일(.wls .kin .ens .qua)이나 저장한 결과(.json)를 앱 창으로 끌어다 놓으면 바로 열립니다.
- 작업 표시줄 아이콘을 오른쪽 클릭하면 정량분석·스펙트럼·광합성·기기 탭으로 바로 갈 수 있습니다.
- 기기 연결(USB)은 브라우저에서와 똑같이 됩니다.

[문제가 생기면]
- 검은 창이 바로 꺼지거나 오류가 나면: 학교 PC에서 PowerShell이 막혀 있을 수 있습니다. 방법 2를 쓰세요.
- "이미 실행 중입니다" 라고 나오면: 이미 켜져 있는 것이니 열린 브라우저를 쓰면 됩니다.
- "다른 사이트나 프로그램이 이미 쓰고 있습니다" 라고 나오면: 아래 [여러 사이트를 각각 설치하기]를 보세요.

[여러 사이트를 각각 설치하기]
브라우저는 "주소(포트 포함)"로 앱을 구별합니다. 두 사이트가 같은 주소(예: localhost:8765)를 쓰면
하나의 앱으로 겹쳐 설치되고 저장 공간도 섞입니다.
- 이 앱은 자기만의 포트 41200 과 고유 이름표(manifest id: uv1200-web-control)를 씁니다.
- 다른 사이트에도 이 start-windows.bat 방식을 쓴다면, 그 사이트의 tools\port.txt 를 다른 번호
  (예: 41300, 41400 …, 1024~65535 사이)로 정하고, manifest.webmanifest 의 "id" 도 서로 다르게 하세요.
- 두 서버를 동시에 켜 둘 수 있습니다. 각 검은 창은 자기 사이트만 보여 줍니다.
- 예전에 localhost:8765 로 설치한 UV1200 앱이 있다면: 그 앱에서 [파일 → 저장]으로 결과를 저장해 두고,
  앱 창 오른쪽 위 ⋯ → "앱 제거"로 지운 뒤 새로 설치하세요. 저장한 파일은 새 앱에 끌어다 놓으면 열립니다.
